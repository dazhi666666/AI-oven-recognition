# A-02：已知高度网格的厚度与体积

本轮边界：只验证完美/缺失的人工物理网格上的公式。不是图像像素网格；不做深度转三维、托盘拟合、分割、补洞或真实食材精度评测。

## 输入和输出

`oven_stereo.geometry.measure_height_grid` 接收四个数组/标量和两个编号：

| 输入 | 约定 |
|---|---|
| `height_m` | 非空二维实数数组；每个托盘格沿支撑平面法向的高度，单位 m |
| `cell_area_m2` | 正且有限的标量，或同形状面积数组；支撑平面上的物理面积 m²，不是图像像素面积 |
| `target_mask` | 同形状 bool；外部给定、确认过的目标区域，`roi_source=reference` |
| `valid_mask` | 同形状 bool；可靠高度格。False 或 NaN/Inf/负高度的格在输出中为 NaN + False |
| `sample_id/config_id` | 非空字符串，追溯样本与配置 |

假定每格代表完整小面积，边界与格子对齐，无重叠，物体可用单值非负高度描述，底面贴支撑面且内部实心。空腔、悬空或多层目标不能直接解释为真实实体积。调用方负责这些物理前提。

共享输出新增 `contracts.GeometryResult`，不会改变现有 `DepthResult`。保存 `height_m/cell_area_m2/target_mask/valid_mask.npy` 和 `result.json`。

- `thickness_mm`：目标格最大有效高度 ×1000，不是 H95。
- `volume_ml`：Σ(h×A) ×1,000,000，乘法和累加均 float64。
- `coverage`：有效目标格数 / 全部目标格数，按格计数，不按全图或面积。
- `ok`：全部目标格可靠，输出完整测量；不把部分覆盖的积分冒充完整体积。
- `empty`：给定目标掩膜为空，体积和厚度都约定为 0；覆盖率为 null（分母 0）。这不是自动判断空托盘。
- `rejected`：目标格缺数据/高度非法或计算溢出；厚度与体积均 null，不填 0、不补洞。
- 形状、掩膜类型、面积错误直接 `ValueError`。目标以外缺高度不影响测量。
- `tray_plane=null`：A-02 不知道相机坐标下的平面；输入高度已经相对已知支撑面。后续 A-03 才连接深度和三维。

## 首次运行前固定的验收条件

| 用例 | 独立预期 | 固定绝对容差（rel=0） |
|---|---|---|
| 100×60 个 1 mm² 格，h=20 mm | 20 mm；120 mL；coverage=1；ok | float64：1e-9 mm/mL；float32 输入：1e-5 mm/mL |
| 已确认空目标掩膜 | empty；0 mL、0 mm；coverage=null | 精确比较 |
| 任一目标格无效/NaN/Inf/负值 | rejected；两个测量值均 null | 精确比较 |
| 10/30 mm 高度，100/200 mm² 面积 | 30 mm；7 mL | 普通浮点近似比较 |
| 负/零/非有限面积、形状不一、非 bool 掩膜 | ValueError | 不允许自动广播掩膜 |

预期值来自长宽高和手算，运行后不按结果放宽容差。60×100 是单元数量，不是 61×101 个边界节点。用例配置见 `configs/geometry/a02_demo.yaml`。

## 复跑

在仓库根目录运行；依赖安装见 readme，不另外安装版本：

```bash
source .venv/bin/activate
python -m pytest -q tests/geometry/test_height_grid.py
python - <<'PY'
from datetime import datetime
from pathlib import Path
import numpy as np
import yaml
from oven_stereo.geometry import measure_height_grid

cfg = yaml.safe_load(Path('configs/geometry/a02_demo.yaml').read_text())
out = Path('results/A-02') / datetime.now().strftime('%Y%m%d-%H%M%S-%f')
out.mkdir(parents=True, exist_ok=False)
shape = tuple(cfg['grid_shape'])
height = np.full(shape, cfg['height_m'], dtype=np.float64)
for state in ('block', 'empty', 'invalid'):
    target = np.full(shape, state != 'empty', dtype=bool)
    valid = np.ones(shape, dtype=bool)
    if state == 'invalid':
        valid[tuple(cfg['invalid_cell'])] = False
    result = measure_height_grid(
        height, cfg['cell_area_m2'], target, valid,
        sample_id=state, config_id=cfg['config_id'])
    result.save(out / state)
    print(state, result.summary())
print(out)
PY
```

每次生成独立结果目录，四个 `.npy` 和严格 JSON 可交给 D 独立读取。算法只接收数组，没有读取文件或标准答案的入口。这个短示例只是展示调用，不是团队的统一运行命令，也没有取代 D 的评测工具。
