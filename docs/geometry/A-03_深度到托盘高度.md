# A-03：从深度到托盘法向高度与面积

本轮把 C 输出的左相机深度图接到 A-02：深度反投影为三维点，利用外部给定的托盘区域拟合平面，沿托盘法向计算高度，再按每个像素在托盘平面上的真实投影面积积分体积。

这一步已在已知答案的人工正视、倾斜托盘上算对；还没有实现自动找托盘/食物、抗离群平面拟合，也不代表仿真、实拍或板端精度达标。

## 坐标和符号约定

以下约定同时交给 B-03 仿真使用：

| 项目 | 约定 |
|---|---|
| 原点 | 校正后左相机光心 |
| x 轴 | 图像向右 |
| y 轴 | 图像向下 |
| z 轴 | 镜头向前，进入场景 |
| 像素坐标 | `u` 向右、`v` 向下；整数坐标表示像素中心 |
| 深度 `Z` | 点沿左相机 z 轴的坐标，单位 m；不是光心到点的欧氏距离 |
| 反投影 | `X=(u-cx)Z/fx`，`Y=(v-cy)Z/fy`，`Z=depth_m` |
| 托盘平面 | `n·X+d=0`；`n` 为单位向量，统一朝相机/食物侧，因此 `d>0` |
| 托盘法向高度 | `h=n·X+d`；托盘点约为 0，朝相机/食物侧为正 |

正视托盘在 `Z=1 m` 时，平面可写成 `n=(0,0,-1), d=1`。食物表面若在 `Z=0.8 m`，法向高度为 `0.2 m`。托盘倾斜时仍用平面法向距离，不能直接用托盘深度减食物深度。

## 公共接口

新增两个共享格式：

- `contracts.PinholeIntrinsics`：左相机针孔内参、标定编号和对应分辨率。内参与深度图分辨率不一致时拒绝计算。
- `contracts.TrayPlane`：单位法向量、平面偏移、拟合 RMS 和参与拟合的可靠托盘点数。

`geometry.measure_depth_geometry` 接收：

- `depth_m` 和 `depth_valid_mask`：C 输出的左相机 z 深度及有效掩膜；
- `target_mask`：外部给定的目标区域；
- `tray_mask`：外部给定、用于拟合平面的裸露托盘区域，不能和目标区域重叠；
- `PinholeIntrinsics`、样本编号、配置编号；
- 可选的平面拟合 RMS 上限和负高度数值容差。

输出沿用 `contracts.GeometryResult`，并写入 `method=depth_plane_height_integral` 和实际 `tray_plane`。A-02 的 `height_grid_integral` 输出仍保持兼容。

内部拆成四步，方便 B/C/D 单独核对：

1. `backproject_depth`：深度转三维点，无效点为 NaN + False；
2. `fit_tray_plane`：对可靠托盘点做最小二乘平面拟合，少于 3 点、近似共线或 RMS 超限时拒绝；
3. `support_plane_cell_areas`：把每个像素的四个边角射线投到托盘平面，用两个三角形求该像素在支撑平面上的面积；
4. `measure_height_grid`：复用 A-02 的完整覆盖、厚度和体积规则。

面积是像素在托盘支撑平面上的足迹面积，不是食物表面的斜面面积。模型适用于能由一张非负高度图描述、底面贴托盘且内部实心的目标；悬空、空腔、多层遮挡不能直接解释为真实实体积。

## 人工验收用例

| 用例 | 已知答案 | 检查内容 |
|---|---|---|
| 正视托盘 `Z=1 m`，目标 `Z=0.8 m` | 高度 200 mm；单元面积 `1/(fx·fy) m²` | 反投影、法向方向、面积、厚度与体积 |
| 倾斜平面上方 40 mm 的平行表面 | 每个目标点高度 40 mm | 不能用 z 方向相减代替法向高度；保存平面元数据 |
| 目标深度无效 | `rejected`，覆盖率 0，厚度/体积 null | 不补 0、不输出部分体积 |
| 托盘点少于 3 个或共线 | `ValueError` | 不输出没有几何意义的平面 |
| 掩膜形状错误或目标/托盘重叠 | `ValueError` | 输入边界固定 |

人工用例配置见 `configs/geometry/a03_demo.yaml`。复跑：

```bash
source .venv/bin/activate
python -m pytest -q tests/geometry/test_depth_geometry.py
```

## 当前边界和下一步

- 当前托盘/目标掩膜来自外部参考，`roi_source=reference`；尚未做自动分割。
- 平面拟合是普通最小二乘，没有 RANSAC 或其他离群点剔除；真实深度数据接入前不能把人工数据结果当成鲁棒性结论。
- 像素射线若不能向前与托盘平面相交，整张面积网格拒绝生成。
- 本轮使用 float64 保证参考计算清楚；尚未做 RK3506 定点化、速度、内存或 MMAC 测量。
- B-03 可按本文坐标生成深度、托盘掩膜、目标掩膜和尺寸真值；随后由 A/C/D 串起第一个虚拟烤箱全过程。
