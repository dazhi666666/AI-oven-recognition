# B 岗工作分析与开工清单

日期：2026-10-22。依据当前 [B 岗任务书](../ai/B_数据与硬件任务说明.md)、[任务规划](../ai/01_任务规划.md)、[共同约定](../ai/00_共同约定与接口.md) 和 [路线图](../路线图.md)。这是一份执行分析，不替代团队尚未拍板的决定。

## 1. 通俗地说，你是做什么的

你负责准备“考题、标准答案和实验条件”：给队友可靠的左右照片，说明相机参数，记录物体真正的尺寸，让算法的好坏有依据；后期还负责台架、成本和功耗证据。

最新分工叫“数据与硬件”。相机标定算法、图像校正、厚度体积计算和板端集成主要由 A 推进；你负责支撑这些工作的采集台架、测量记录和独立复核数据。

## 3. 现在就能推进的顺序

1. **先交 B-01。** 本次已完成代码、原始文件、清单、独立核对点和复跑说明，并用 C 的现有入口成功输出数值结果。现在可以让 C 用正式配置复核，让 D 接入独立打分。
2. **并行推进 B-02。** 本次已整理三种公开参考产品和成本/功耗草案；缺的真实报价留空，口径交团队与 D 确认，不能先宣布“便宜 40%”。
3. **准备 B-03 小样。** 第一个场景只放托盘和已知尺寸的方块。相机、灯光、材质、随机种子写进配置。先核对深度、坐标、掩膜，再扩量；正式接口需要 A 的确认。
4. **提前盘点台架物料。** 能做的是列清单、找可借器材和准备记录表；相机选型、采购与实物搭建依赖真实设备信息。
5. **先定采集与划分原则。** 同一物体/场景的近似重复帧按组划分开发和测试，避免答案泄漏；与 D 冻结口径后再批量生成和采集。

这不是按自然日作出的工期承诺。先测一小批的渲染/采集耗时，再估算 3000/500 对的时间。

## 4. B-03 开工前要对齐的细节

- 左右相机的焦距、主点、基线、分辨率、姿态和世界坐标到相机坐标的变换。
- 托盘的平面方程、法向朝向、已知尺寸、方块位置以及厚度/体积真值。
- `depth_m` 是沿光轴的 Z，不能把“沿像素射线的距离”直接当 Z；渲染输出必须核验其定义和单位。
- 第一阶段用不透明、有纹理的简单物体验证；反光/透明的表面标签和失效区域要另定义，不能把透过玻璃的背景深度当食物表面真值。
- 蒸汽/油污的图像效果属于仿真假设，效果看起来像不等于环境性能已验证；后续要用实拍对照。
- 先做一小批检查：相机实际投影与标定一致，左右对应关系正确，规则方块尺寸可复核，同一配置和种子在固定环境下可复现。

## 5. 采集记录最少应包含什么

样本编号、物体编号、拍摄批次/日期、左右相机编号、左右时间戳、实际同步时间差、标定版本、图像尺寸、物体尺寸/单位、测量工具及分辨率、重复测量记录、距离与温度、光照/污染条件、数据划分、操作者、原文件路径及校验值。实拍规则物体的长宽高不等于每个像素的稠密深度真值，标签种类必须写清。

## 6. 你能从中学到什么

- **数据工程：** 文件读取、格式转换、单位检查、异常处理、清单、版本与 Git 协作。
- **计算机视觉基础：** 为什么左右图能测距，焦距、基线、主点差、标定和无效掩膜如何影响结果。
- **仿真自动化：** 从小型三维场景开始，用脚本控制相机和光照并批量产生可追溯的数据。
- **实验与测量：** 如何记录真实尺寸、控制变量、留出独立测试集、区分仿真/实拍/板上结果。
- **工程判断：** 读规格书、识别不同精度定义、核算成本和功耗，给结论附证据。
