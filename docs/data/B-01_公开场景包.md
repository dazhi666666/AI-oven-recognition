输入清单：[middlebury_adirondack_input.json](../../data/manifests/middlebury_adirondack_input.json)；答案清单：[middlebury_adirondack_reference.json](../../data/manifests/middlebury_adirondack_reference.json)。各文件的下载 URL、字节数、SHA256、查询日期已登记。四文件合计 35,002,048 字节，约 33.4 MiB。

## 2. 文件与接口

| 原始文件 | 含义 | 本地位置 |
|---|---|---|
| im0.png | 左相机原图 | `data/raw/middlebury/Adirondack-perfect/inputs/` |
| im1.png | 右相机原图 | 同上 |
| calib.txt | 该分辨率的已校正标定 | 同上 |
| disp0.pfm | 以左图为准的浮点视差真值 | `data/raw/middlebury/Adirondack-perfect/reference/` |

图片、原标定和答案字节保持原样。原始文件、派生数组和运行结果不进 Git，队友通过清单重新获取。

- `load_middlebury_sample()` 返回公共 `contracts.StereoSample`，只读左右图和标定；其 `.calibration` 是现有 `RectifiedStereo`，完整内参在 `.calibration_metadata`。各字段对应共同约定 5.1。
- `load_middlebury_reference()` 单独返回 `contracts.ReferenceData`，答案不放进 `StereoSample`。
- `load_gray_pair()` 返回 uint8 灰度数组，原彩色 PNG 不重新编码。OpenCV 的 BGR/BGRA 解码在转灰度时处理。
- 没有答案目录时，输入读取和 C 的运行仍可完成；有自动测试覆盖这种情况。
- 当前读取器明确支持 `Middlebury 2014/perfect`；其他版本/数据集需另核对，不猜单位或校正状态。

## 3. 已核对的约定

| 项目 | 本场景实值或处理 |
|---|---|
| 左右顺序 | 按官方定义，im0 是左图、im1 是右图；`d=xL-xR` |
| 分辨率 | 原图和标定均为 2880×1988 |
| 焦距 | 4161.221 px |
| 基线 | 原文件 176.252 mm，接口中为 0.176252 m |
| 主点差 | 1654.636 − 1445.577 = 209.059 px，使用 `d + doffs` |
| 校正 | perfect 版本，原文件 `dyavg=0`、`dymax=0`；未自行再次校正 |
| PFM | `Pf`，2880×1988，头部 scale=-0.003922，小端；文件底行先存，读取后翻转 |
| PFM 数值尺度 | 按 Middlebury 使用约定和老师所指 RAFT 读取方法，原始浮点数就是像素视差，**不再乘 0.003922** |
| 无效值 | 原始 `inf` 等非有限值转成 NaN，并给 bool 掩膜；有限的 0 不擅自当无效 |
| 深度 | 参考换算 `Z_m = 0.176252 × 4161.221 / (d + 209.059)`；非正分母或非有限结果标无效 |

PFM 处理核对了 [RAFT-Stereo 原始 readPFM 实现](https://github.com/princeton-vl/RAFT-Stereo/blob/main/core/utils/frame_utils.py)。本实现按任务需要独立编写，只读单通道视差；不能据此推断任意 PFM 文件的缩放约定。

答案有效像素 5,691,206 / 5,725,440，约 99.4021%；这是**真值存在的比例**，不是算法成绩。

## 4. 独立数值核对

核对结果保存在 [B-01_独立核对点.csv](B-01_独立核对点.csv)。坐标是从左上角开始的零基 `(x,y)`。

选 5 个固定位置及 1 个无效位置，用 Python 标准库 `struct` 直接寻址原始 PFM 字节、`Decimal` 计算参考深度。预期值未调用 B 的 PFM 读取函数或 C 的深度换算；再与准备包中的数组比较。

| (x,y) | 原始视差 px | 独立参考深度 m |
|---|---|---|
| (1000,200) | 50.71357727050781 | 2.823329280550916 |
| (1600,700) | 90.5901107788086 | 2.447607876378415 |
| (2400,1200) | 182.86119079589844 | 1.871359376006089 |
| (1000,1800) | 145.27813720703125 | 2.069846614083460 |
| (2400,200) | 110.9863510131836 | 2.291623738230111 |
| (2501,17) | inf | 无效；准备结果必须为 NaN，掩膜 false |

5 个有效点的深度差均小于 1e-6 m（最大约 1.18e-7 m）。这个容差检查的是读取和浮点换算一致性，**不是相机或预测深度的物理精度**。

独立复核核心示例（在仓库根运行；以第一个点为例）：

```python
import struct
from decimal import Decimal
from pathlib import Path

path = Path("data/raw/middlebury/Adirondack-perfect/reference/disp0.pfm")
with path.open("rb") as f:
    assert f.readline().strip() == b"Pf"
    width, height = map(int, f.readline().split())
    scale = float(f.readline())
    offset = f.tell()
    x, y = 1000, 200
    f.seek(offset + 4 * ((height - 1 - y) * width + x))
    d = struct.unpack("<f" if scale < 0 else ">f", f.read(4))[0]
z = Decimal("0.176252") * Decimal("4161.221") / (Decimal(str(d)) + Decimal("209.059"))
print(d, z)  # 50.71357727050781，约 2.823329280550916 m
```
