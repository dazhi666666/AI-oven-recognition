## 1. 一句话

**相机这一头的事都归你：选模组、标定、自动校正、从距离算出厚度和体积，最后把程序搬上板子。**

这些工作共用同一套相机模型和坐标约定，交给一个人负责，就不会出现"标定一套坐标、算体积另一套坐标"的问题。

## 2. 你负责什么

- **选模组**：找候选模组，算视差，给出摄像头间距和视角的依据；摸清板子的算力。
- **标定与校正**：标定误差 ≤0.5 像素；生成把左右图"摆正"的映射表，适配不同分辨率，并提供板子上用的查表格式。
- **自动校正**：运行中发现摄像头偏了能自动修正；做温度补偿。
- **几何**：三维点、托盘平面、高度地图、厚度和体积；定义什么情况下拒绝给数；做一个简单的自动找食物区域。
- **板子**：交叉编译、板上程序框架、校正和几何的板上实现、测量工具、最终集成和演示。

**代码主要写在：**
- `src/oven_stereo/calibration/`、`geometry/`
- `edge/`（匹配部分 `edge/src/match/` 由 C 写）
- `configs/calibration/`、`geometry/`、`hardware/`


## 3. 当前任务

### A-01 模组选型与预算推算（第 2 周末前，最优先）

**为什么最优先：** 采购最花时间。模组晚到一周，标定、实拍、上板全部顺延一周。

**做什么：**

1. **找 2–3 款候选模组。** 要求：两个同型号的普通 RGB 摄像头，固定间距 6–8 cm。每款记录以下信息，并注明出处：
   - 分辨率、视角
   - 接口（MIPI / DVP / USB）
   - 能否同步拍摄
   - 工作温度
   - 价格、交货时间
2. **算视差。** 用公式 `视差(像素) = 焦距(像素) × 间距(米) ÷ 距离(米)`，算出：
   - 每款模组在 0.3 / 1.0 / 1.5 m 处的视差，分别按 320×240 和 160×120 计算；
   - 达到 5% 误差时，视差最多允许错多少像素。

   算完和 architecture.md 第 4 节的推算对照一下。
3. **摸清板子情况。** 手上有没有 RK3506？能不能交叉编译出 hello world 并在板上运行？
4. **和 D 商量计数方法：**
   - 计算量怎么数，比如"差的绝对值 + 累加"算不算一次乘加；
   - 内存算不算两张输入图（约 150 KB）。

**交付：** 选型对比表、视差推算表、板子情况、计数方法建议。交给本人决定买哪款。

### A-02 高度地图算厚度和体积

**为什么做：** 先在完美输入上把公式算对。以后体积不准时，就能排除"公式写错"这种可能。

**输入：**
- 一张高度地图（米，表示每格比托盘高多少）；
- 每格的面积（平方米）；
- 两张掩膜：
  - **目标区域**：哪些格属于食物；
  - **有效区域**：哪些格的数据可靠。

**做什么：**

1. **定义：** 最大厚度 = 目标区域内有效格的最大高度。如果另算 95% 分位高度，单独起一个名字。
2. **公式：**
   - 体积 = Σ(高度 × 面积)，单位立方米，乘 1,000,000 得到毫升；
   - 厚度：米乘 1000 得到毫米。
3. **测试用例**（预期值直接按尺寸写死，不调用被测函数来算）：
   - 方块：底面 100×60 mm，高 20 mm，用 1×1 mm 格子（边界正好对齐），预期厚度 20 mm、体积 120 mL；
   - 空托盘：预期状态 `empty`、体积 0；
   - 错误输入：形状不一致、面积为负、目标区域里有无效格；
   - 目标区域缺数据时，返回 `rejected` 和 `null`，不补洞。

**交付：** 计算函数、测试、运行结果、复跑方法。

**说明：** 这一步只证明公式对，还不涉及标定和真实图像。

## 6. 常见坑

| 坑 | 怎么避免 |
|---|---|
| 用"距离相减"当高度 | 托盘一倾斜就错了。要用托盘平面的法向量来算高度 |
| 把像素高度直接相加当体积 | 远处一个像素对应的面积更大，要按真实面积加权 |
| 体积单位换算错 | 1 立方米 = 1,000,000 毫升 |
| 用 float32 累加大量格子 | 会丢精度，累加时改用 float64 |
| 缺数据填 0 | 体积会偏小。应该拒测，或者明确标注用了什么补洞方法 |
| 把空托盘和"测不了"混在一起 | 空托盘是 `empty`，体积为 0；测不了是 `rejected`，体积为 `null` |
| 用标定图复核标定 | 复核要用没参与标定的图，否则误差会偏小 |
| 用电脑速度推测板子速度 | 板子的数字只能来自板子实测 |
