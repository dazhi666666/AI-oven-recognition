## 2. 计算方法与适用前提

配置：`configs/hardware/a01_candidates.yaml`；函数：`oven_stereo.calibration.budget.estimate_disparity_budget`。

- 每眼宽度为 W，使用**水平**视角 θ：`f_px = W / (2 tan(θ/2))`。型号名中的 83° / 92° 是对角视角，不能代入。
- 暂按缩小后保留水平视场、无额外水平裁切、近似针孔成像、`doffs=0` 规划，`d=fB/Z`。原始宽高比改变、畸变校正和裁切会改变实际内参，必须后续标定；160×120 指每眼，不是拼接图。
- 一阶误差预算：`|δd| ≈ εd`。
- 若要求正负两个方向的距离相对误差都不超过 ε，固定 f、B 且只考虑视差误差，严格对称界限是 `|δd| ≤ εd/(1+ε)`。来自 `Z估/Z真=d/(d+δd)`，不是额外实测结论。
- 下表均按 ε=5% 计算，单位为像素，四舍五入仅用于展示；不包括标定、同步和基线误差。绝不能把全部误差预算都视为匹配算法独占的额度。

### 和架构的对照

架构参考设计 B=70 mm、HFOV=70°，不是任一候选的实测参数：

| 每眼尺寸 | f | d（0.3 / 1.0 / 1.5 m） | 5% 一阶预算（同顺序） |
|---|---:|---|---|
| 320×240 | 228.5037 | 53.3175 / 15.9953 / 10.6635 | 2.6659 / 0.7998 / 0.5332 |
| 160×120 | 114.2518 | 26.6588 / 7.9976 / 5.3318 | 1.3329 / 0.3999 / 0.2666 |

与架构的约 26.6、8、5.3 px 一致。架构 1.5 m 一行给出的约 0.53 px 是 **10%** 档，本次 A-01 按要求全表使用 **5%**，对应约 0.2666 px，不能混用。

推论：候选视角更宽、基线更短，160×120、1 m 的视差容错比参考设计更紧，仅约 0.28–0.32 px（一阶）。320×240 的近处视差又超过 32 px，因此不能给两个分辨率无条件共用固定 32 档搜索。这里不修改 C 的配置，等实际标定后共同调整。

## 4. 给 D 的计数建议（待讨论，不是已达成约定）

1. MAC 按一次乘法和一次累加为一组，同时分别报告整数加/减、绝对值、比较、查表、除法和数据搬运。SAD 的绝对差加累加不应未经说明强行算成一次 MAC；若要折算，另列权重和依据。
2. 同时报告算法工作区与包含输入/输出、映射表、栈的峰值总内存，列清是否包含驱动/系统缓冲。并发持有的缓冲按生命期计数，不把不同时存在的全部数组机械相加；需 D 最终确定 200 KB 的验收口径。
3. 原始计数用字节，另报 KiB（÷1024）和 kB（÷1000），不混淆：两张 320×240 uint8 灰度图是 153600 B = 150 KiB；两张 RGB 是 460800 B = 450 KiB。160×120×32 的 uint8 全代价表是 614400 B = 600 KiB，确实超预算。
4. 校正、匹配、几何分别计时，深度 FPS 和完整流程 FPS 分开。所有板端数字必须来自实际设备，不能用 PC 推算。功耗交由 B 实测。

```bash
source .venv/bin/activate
python -m pytest -q tests/calibration/test_budget.py
python - <<'PY'
from pathlib import Path
import yaml
from oven_stereo.calibration.budget import estimate_disparity_budget
cfg = yaml.safe_load(Path('configs/hardware/a01_candidates.yaml').read_text())
for item in [dict(candidate_id='architecture_reference', **cfg['reference_design']), *cfg['candidates']]:
    for width, height in cfg['image_sizes_px']:
        for distance in cfg['distances_m']:
            result = estimate_disparity_budget(
                image_width_px=width, horizontal_fov_deg=item['horizontal_fov_deg'],
                baseline_m=item['baseline_m'], distance_m=distance,
                relative_depth_error=cfg['relative_depth_error'])
            print(item['candidate_id'], (width, height), distance, result)
PY
```
