# 依赖版本选择

2026-10-21

| 依赖 | 锁定版本 | 允许范围（pyproject） | 为什么选它 |
|---|---|---|---|
| Python | 3.11（推荐） | ≥3.11, <3.15 | 本机就是 3.11.5；各依赖在 3.11–3.14 都有现成安装包 |
| numpy | 2.3.5 | ≥2.3, <2.5 | 2.3 系列的最后一个补丁版，已经稳定、不再变动。1.26 太旧，在 Python 3.13 以上没有安装包 |
| opencv-python-headless | 4.13.0.92 | ≥4.13, <5 | 4.x 系列成熟，SGBM 等接口稳定。选 headless（无窗口界面）版本：体积小，不会与 GUI 库冲突；调试图存成 PNG 查看即可。没有选刚出的 OpenCV 5.0，因为大版本变化可能改接口 |
| PyYAML | 6.0.3 | ≥6.0, <7 | 读配置文件用，6.0.3 是最新补丁版 |
| pytest | 9.0.3 | ≥9.0, <10 | 本机已在用 |

**暂不加入的依赖：**
- PyTorch 等学习框架：M3 做学习方法时再定。
- matplotlib：需要画图时再加。

**验证情况**（Windows，Python 3.11.5，项目内 `.venv`）：
- 按锁定版本安装后，`pip check` 无冲突，`pytest` 8 项通过。
- 额外检查了 SGBM：输出为放大 16 倍的 int16，能正确恢复 8 像素的人工平移。
- 打分例子（误差中位数 10%、覆盖率 2/3）、PNG 读写、YAML 读取都正常。

**注意：** `requirements-lock.txt` 只用英文注释。中文 Windows 上，较旧的 pip 会按 GBK 编码读这个文件，遇到中文会直接报错。

**以后升级：** 先在自己的 `.venv` 里装新版本并跑通测试，再改锁定文件，并在任务记录里提一句。
