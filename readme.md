# 双目立体视觉深度感知与三维重建

单份课题任务书（独立可读）｜团队规模：4人（硬件预算前置）｜硬件考核基准：基于和而泰智灵平台RK3506（三核 ARM Cortex-A7 + 单核 Cortex-M0 @ 1.5 GHz、单精度 FPU、无独立 NPU、内置 128 MB DDR、外置 256 MB Flash）

**一句话说明**：用两枚普通 RGB 摄像头（双目立体视觉 = 像人眼一样由左右图像的视差推算距离）+ 纯算法，获得家电腔体的深度与三维结构，交付**家电级双目视觉深度模组**——结构光/飞行时间（ToF）路线的低成本替代方案。

## ① 背景与价值（为什么做）

· **技术与产业背景**：双目立体视觉在汽车辅助驾驶、机器人避障、手机增强现实上已成熟商用（相机标定、立体匹配、深度估计与三维重建全链路都有成熟算法与开源实现）；本课题把它迁入**家电 / 厨电腔体**。

· **要解决的痛点**：烤箱"自适应温控"需要知道腔体内食材的体积/厚度；但结构光 / 飞行时间（ToF）模组成本仍偏高，且其**投影/发射单元在高温、油污、蒸汽环境下易受损、视窗易污染**。冰箱、洗碗机等腔体同样需要低成本的"体积/占据感知"。需求主体：**对物料成本极敏感的厨电整机厂**。

· **量化目标**：在 0.3–1.0 m 工作区间内，深度相对误差中位数 ≤ 5%；并**不引入主动光源与专用 AI 加速器**——两枚普通摄像头 + RK3506 级算力完成（详见 ③ 验收指标）。

· **技术难点**：① 食材表面弱纹理、金属容器与水面反光、玻璃与保鲜膜透明——经典立体匹配在这些区域大面积失败；② 弱光偏色照明、蒸汽散射、视窗油污放大左右相机成像差异；③ 立体匹配计算量大，需在 RK3506 算力预算内达到可用帧率；④ 低成本模组装配误差与温漂直接变成深度误差，需要自标定方案兜底。

· **交付形态**：**家电级双目视觉深度模组**参考方案——物料成本更低、无发射单元、高温环境更耐受。

· **考核口径说明**：本课题定位为"**纯 RGB 低成本替代路线**"，与结构光 / ToF 路线形成对照与互补；全部精度指标以开题冻结的评测协议为准。

## ② 任务定义（输入 / 输出 / 边界）

· **硬件与算力基准**：主控按公司智能控制器主流等级——RK3506（三核 ARM Cortex-A7 + 单核 Cortex-M0 @ 1.5 GHz、单精度 FPU、无独立 NPU、内置 128 MB DDR、外置 256 MB Flash），**无独立 AI 加速器**；双目模组为两枚同型号 RGB 传感器 + 固定基线（60–80 mm，开题冻结）。

· 输入：低成本双目 RGB 模组；目标场景为烤箱/蒸烤箱腔体（可用等效台架或实机）。

· 输出：① 立体标定与自标定流程；② 双目深度估计算法（含弱纹理与高光/透明区域处理策略）；③ 点云 / 体积估计与端侧部署；④ **路线对标三联表**（精度 / 成本 / 功耗 + 环境耐受，对比结构光/ToF 路线）；⑤ 范围取舍决策文档。

· 边界：不追求通用深度相机精度（以满足"体积/厚度估计"家电任务为准）；不引入主动光源；光学安全按实验室规范。

## ③ 可验证验收指标（以开题冻结的评测协议为准）

· **深度精度**：0.3–1.0 m 相对误差中位数 ≤ 5%、95 分位 ≤ 10%；1.0–1.5 m 中位数 ≤ 10%；

· **有效覆盖率**：普通场景有效深度像素占比 ≥ 85%；弱纹理 / 高光 / 透明专项场景 ≥ 60%（处理后），并显式报告失败区域比例；

· **体积/厚度估计**：以几何真值（卡尺 / 参照物）对照，规则目标物误差 ≤ 10%；

· **端侧资源（RK3506 口径实测）**：深度帧率 ≥ 5 fps（输出 160×120、采集 320×240 下采样）；单帧等效运算 ≤ 12 MMAC（MMAC = 百万次乘加）；SRAM 峰值 ≤ 200 KB；算法代码 + 常量 ≤ 300 KB Flash；

· **标定与稳定性**：出厂一次标定 + 运行自校正；重投影误差维持 ≤ 0.5 像素；模组环境温度 0–70 °C 内精度指标衰减 ≤ 20%；模拟油污视窗下有效覆盖率下降 ≤ 20 个百分点，并给出污染提示；

· **功耗与成本**：模组功耗 ≤ 1.5 W；BOM 相对同量程结构光 / ToF 模组下降 ≥ 40%（核算口径开题冻结）。

## ④ 数据工程规范（仿真 / 金标 / 质检 / 过程管理）

· **仿真优先**：仿真生成双目图像对 + 深度真值 ≥ 3000 对（覆盖腔体几何、≥ 3 种材质、≥ 4 档距离、≥ 3 档纹理/光照）；

· **金标实拍**：实拍 ≥ 500 对，附几何真值测量记录（卡尺 / 参照物）；标定文件版本化；

· **退化矩阵**：光照 / 蒸汽 / 视窗油污 / 透明与高光物体 4 类退化条件专项数据；

· **质检**：抽检 ≥ 10%；记录数据贡献者；

· **入组审核**：课题入组与数据规范执行情况由校企联合工作组按统一流程评审。

## ⑤ 技术路线与基线

· 基线一（问题基线）：**经典立体匹配**（块匹配 / 半全局匹配）在退化矩阵上的误差；

· 基线二（对标基线）：**结构光 / ToF 路线**的公开规格；

· 主线：标定 / 自标定 → 经典匹配基线 → 学习式匹配与深度补全 → 弱纹理 / 高光处理 → 三维重建与体积估计 → 端侧部署（RK3506、DSP 指令优化）→ 矩阵评测与路线对照。

## ⑥ 开发与实验管理规范（het-ai）

· 训练 / 评测脚本遵循公司 het-ai 模型开发规范：参数搜索空间以声明式配置定义；以"深度精度 vs 延迟 / 算力"多目标对比；实验须支持本地仿真与实拍数据装载与**干运行（dry-run）自检**，通过后方可提交；

· 提交物：代码 + 配置 + 干运行日志 + 评测报告 + 范围取舍决策文档（不含数据本体）。

## ⑦ 里程碑与阶段门禁（M0 开题 → M5 结项）

· M0 开题：模组选型（基线 60–80 mm 冻结）、量化指标与评测协议冻结；

· M1 基线：经典匹配在退化矩阵上的误差实测 + 结构光/ToF 对标数据整理；

· M2 数据与标定：仿真 ≥ 3000 对 + 金标实拍 ≥ 500 对完成；标定流程可用（重投影 ≤ 0.5 像素）；

· M3 深度估计 v1：学习式匹配 / 深度补全在 RK3506 预算内跑通（≤ 12 MMAC/帧）；

· M4 专项与部署：弱纹理 / 高光 / 透明处理达标；三维重建与体积估计；端侧 ≥ 5 fps 演示；

· M5 结项：全部交付物与复现材料齐备。

## ⑨ 依赖与风险

· 依赖：低成本双目模组采购（预算前置）、等效腔体或实机、仿真环境与标定工具；

· 风险与对策：

1. 弱纹理 / 高光区域匹配失败 → 任务收敛为"体积 / 厚度估计"而非稠密深度，并以**区域覆盖率**作为显式指标；
2. RK3506 算力不足 → 降分辨率 + 稀疏深度 + 区域重建；必要时改为"事件触发单次计算"（放入食材后计算一次，单帧 ≤ 1 s），考核口径不变；
3. 与主动式（结构光 / ToF）路线定位易混 → 明确"**纯 RGB 低成本替代路线**"的差异点（成本 / 高温耐受 / 无发射单元）。
